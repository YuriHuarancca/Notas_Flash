# 🪟 Widget de Notas para Windows 11

Widget de notas y editor de texto moderno, fluido y personalizable con estilo **Fluent Design / Mica** para Windows 11, impulsado por **Python + Microsoft Edge WebView2**.

---

## 🚀 Instalación rápida

1. Ve a la carpeta compilada: **[`dist/Widget-Notas-Win11/`](dist/Widget-Notas-Win11/)**
2. Ejecuta **`instalar.bat`** (solicitará permisos de Administrador para instalar en `C:\Program Files`).
3. El instalador configurará automáticamente:
   - Instalación en `C:\Program Files\WidgetNotasWin11`
   - Acceso directo en el Escritorio
   - Acceso directo en el Menú Inicio
   - Opción en el menú contextual de Windows (anticlick): **"Abrir con Widget de Notas"** para archivos `.txt` y `.html`.

Para desinstalarlo limpiamente, ejecuta **`desinstalar.bat`** o desinstálalo desde *Configuración > Aplicaciones instaladas* de Windows.

---

## ✨ Características

- **Diseño Windows 11:** Efecto Mica/Acrílico, esquinas redondeadas y sombra flotante.
- **Cabecera fluida:** Arrastre inmediato desde cualquier parte de la barra superior.
- **Guardado interactivo:** Presiona <kbd>Ctrl+S</kbd> o el botón de guardar para elegir libremente la carpeta y el nombre del archivo.
- **Menú contextual anticlick:** Abre y edita archivos `.txt` y `.html` directamente con el widget.
- **Listas y tareas:** Viñetas, listas numeradas y checklist interactivo.
- **Modo compacto:** Minimiza a una pequeña barra superior con un solo clic.
- **Portabilidad:** También puedes usar la carpeta compilada de forma portable sin instalar.
